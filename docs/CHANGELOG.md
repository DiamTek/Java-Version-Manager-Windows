## [1.0.2] - 2026-09-23

This release delivers an exhaustive defensive security hardening overhaul across the entire JVM runtime engine (`jvm.bat`), UAC elevation boundaries, CI/CD pipelines, and package manifests, accompanied by a comprehensive **116-test automated adversarial security test suite** spanning **27 CWE vulnerability classes** (`CWE-20` through `CWE-918`).

### Security & Defensive Hardening
- **Complete Adversarial Input Sanitization (`:ValidateStrictIdentifier` & `:RejectExclamationArg`)**: Engineered a centralized, multi-stage sanitization pipeline in `jvm.bat` that validates all external inputs across `link`, `unlink`, `which`, `pin`, `exec`, `--vendor`, candidate version switches, candidate installation, uninstallation, and configuration parsing:
  - *Pre-Delayed-Expansion Exclamation Guard (`:RejectExclamationArg`)*: Inspects raw CLI parameters (`%~1`..`%~9`) under `setlocal disabledelayedexpansion` prior to `setlocal enabledelayedexpansion`, preventing `cmd.exe` from silently stripping unpaired `!` characters (`foo!bar` -> `foobar`) during Phase 2 parser expansion.
  - *Win32 Trailing Space & Dot Canonicalization Bypass*: Proactively strips trailing spaces and trailing dots (`.` and ` `) before reserved keyword evaluation, completely neutralizing Win32 filesystem canonicalization bypass attacks that attempted to target or overwrite `current` (e.g., `current.`, `current `, `current....`, `current   `).
  - *NTFS Alternate Data Stream (ADS) Neutralization*: Detects and strips colon stream delimiters (`:`), thwarting hidden NTFS Alternate Data Stream execution vectors (e.g., `test:stream`).
  - *Directory Traversal & Keyword Protection*: Enforces strict rejection of directory traversal sequences (`..`, `/`, `\`), single-dot aliases (`.`), leading hyphen flag injection (`--evil-flag`), and reserved keywords (`current` in `link`, `unlink`, `pin`, and candidate switches).
  - *Poison Character & Quote-Smuggling Neutralization*: Neutralizes dangerous `cmd.exe` command chaining, embedded double-quote smuggling (`set _VSI_DQ="` / `if "!_VSI_CH!"=="!_VSI_DQ!"`), and poison characters (`&`, `|`, `<`, `>`, `^`, `;`, `"`, `*`, `?`) via pure-batch character loop inspection (`:VSI_CharLoop`) and internal substitution checks without spawning subshells or piping untrusted input.
  - *Pipe-Free Subshell Elimination (`jvm doctor`, `jvm list`, & `:SwitchCandidate` — `CWE-78`)*: Replaced piped `echo !VENDOR_RAW! | %FIND_BIN%`, `echo "%%A" | %FINDSTR_BIN%`, and `echo(!PATH! | %FINDSTR_BIN%` subshells with pure in-memory delayed-expansion string substitution checks (`!VAR:sub=!` and `!CHECK_PATH:;!SYMLINK_PATH!\bin;=!`), neutralizing poison characters inside untrusted JDK `release` files and `PATH` entries and emitting `.jvm_session_target` via `:EmitSessionEnv`.
  - *Upstream `LATEST_VER` Post-Resolution Validation (`:InstallCandidate` & `:SwitchCandidate` — `CWE-20`)*: Moved `latest` version resolution (`:ResolveLatestEcosystemCandidate` and directory sorting) **before** `:ValidateStrictIdentifier` so upstream-resolved `LATEST_VER` strings are strictly sanitized against path traversal and poison characters prior to constructing download URLs or directory paths.
  - *DOS Reserved Device & Win32 Device Namespace Rejection (`CWE-66`)*: Blocks legacy DOS 8.3 reserved hardware device names (`CON`, `PRN`, `AUX`, `NUL`, `COM1-9`, `LPT1-9`), extended DOS device names with extensions (`CON.jdk`, `NUL.21`, `AUX.txt`, `COM1.jdk` via base-name extraction before `.`), and Win32 raw device path namespaces (`\\.\`, `\\?\`, `\??\`) in `jvm link`.
  - *Subcommand & Project Config File Hardening (`.java-version`, `.sdkmanrc`, `jvm exec` — `CWE-20` / `CWE-88`)*: Guarded automatic `.java-version` and `.sdkmanrc` parsing with `if not defined CLI_COMMAND` so read-only subcommands (`--version`, `list`, `doctor`) never mutate `.jvm_session_target`; stripped UTF-8 BOM sequences (`ï»¿`), normalized `jdk-`/`java-`/`1.8` prefixes, validated `--vendor` strictly via `:ValidateStrictIdentifier`, blocked `--legacy`/`--registry` mode hijacking inside `.java-version`, and hardened `jvm exec` to execute via `"%CMD_BIN%" /d /s /c ""!EXEC_CMD!""` with AutoRun disabled (`/d`) and whitespace-only command rejection.
- **System32 Binary Pinning, Canonical Global Install & Shortcut Target Hardening (`CWE-426` / `CWE-427` / `CWE-428`)**:
  - Added `%SystemRoot%` spoofing fallback (`if not exist "%SystemRoot%\System32\cmd.exe" set "SystemRoot=C:\Windows"`), pinned all external Windows system binaries (`cmd.exe`, `reg.exe`, `find.exe`, `findstr.exe`, `where.exe`, `choice.exe`, `timeout.exe`, `fsutil.exe`, `powershell.exe`, `chcp.com`, `icacls.exe`, `attrib.exe`, `explorer.exe`) to `%SYS32%` (`%..._BIN%`), and enforced `NoDefaultCurrentDirectoryInExePath=1`, completely preventing current-working-directory (CWD) binary planting and `PATH` search-order hijacking when invoking `jvm` inside untrusted repositories.
  - Updated all `where.exe` call sites (`jvm list`, `jvm which`, `jvm doctor`, and active binary resolution) to `%WHERE_BIN% $PATH:java`, forcing `where.exe` to search strictly `%PATH%` and never an untrusted current working directory.
  - Hardened `:InstallGlobalCommand` (`CWE-427`) to copy `jvm.bat` into canonical `%LOCALAPPDATA%\DiamTek\JVM\bin` (guarded with `fsutil reparsepoint query` and `icacls /inheritance:r`) rather than registering an arbitrary `SCRIPT_DIR` into `HKCU\Environment\Path`, while preserving unexpanded `%...%` tokens via `DoNotExpandEnvironmentNames`.
  - Hardened `install.ps1` (`CWE-428`) to fail closed if `$systemPowerShell` (`System32\WindowsPowerShell\v1.0\powershell.exe`) is missing (removing the unpinned `"powershell.exe"` fallback), added `-NonInteractive` and `-Quiet` to `QuietUninstallString`, and pinned Start Menu `.lnk` shortcut `TargetPath` to `$sysCmd` (`System32\cmd.exe`) or `$wtCandidate`.
  - Hardened all 60+ `for /f ('%..._BIN% ...')` command loops (including `!CURR_JAVA_BIN!` version detection) to preserve inner argument quoting around `-Command "..."` and registry queries without `cmd.exe /c` outer-quote stripping.
- **ACL-Locked & Reparse-Safe Isolated Temp & Registry Backup Workspaces (`:EnsureSecureTemp`, `:BackupRegistry`, & `:EmitSessionEnv` — `CWE-276` / `CWE-330` / `CWE-377` / `CWE-378` / `CWE-532`)**:
  - Migrated temporary helper scripts and `.jvm_session_target` files out of world-writable shared `%TEMP%` into an ACL-locked per-user workspace (`%LOCALAPPDATA%\DiamTek\JVM\temp`) verified against reparse points (`%FSUTIL_BIN% reparsepoint query`) before and after creation, and hardened atomically via `icacls /inheritance:r /grant:r "*S-1-5-18:(OI)(CI)F" "*S-1-5-32-544:(OI)(CI)F" "%USERNAME%:(OI)(CI)F"` with fail-closed exit checking (`if errorlevel 1 exit /b 1`).
  - Hardened `:BackupRegistry` (`CWE-532` / `CWE-276`) to verify `%LOCALAPPDATA%\DiamTek\JVM\backups` against NTFS reparse points (`%FSUTIL_BIN% reparsepoint query`) and lock down directory permissions with `icacls /inheritance:r` prior to invoking `reg export` on `HKCU\Environment` and `HKLM\...\Environment`.
  - Eliminated 100% of predictable 15-bit `!RANDOM!` / `%RANDOM%` temporary filenames across `jvm.bat` (`CWE-330`), replacing every temporary script and verification output path with CSPRNG `[System.IO.Path]::GetRandomFileName().Replace('.', '')` to guarantee parallel terminal session isolation without cross-instance interference.
  - Added `:EmitSessionEnv` to validate `JVM_CALLER_PID` strictly as a positive numeric PID (blocking `..`, `/`, `\`, and `-`) before writing `.jvm_session_target_<PID>`, and synchronized `install.ps1` (`$profileCode`) with `:InstallPowerShellHook`.
- **Transport Security, Vendor Host Allowlisting, Open Redirect Defense & Failure-Path Cleanup (`:SelfUpdate`, `:ExecuteSharedDownloader`, & `:VerifyDownloadedScript` — `CWE-295` / `CWE-319` / `CWE-345` / `CWE-354` / `CWE-459` / `CWE-494` / `CWE-601` / `CWE-918`)**:
  - Enforced TLS 1.2 + TLS 1.3 (`[Net.ServicePointManager]::SecurityProtocol = 3072 -bor 12288`) and strict `https://` URI scheme validation on `$env:DL_URL`, `$env:DL_CHKSUM_URL`, and post-redirect `$response.ResponseUri`, blocking plaintext `http://`, `file://`, and UNC downgrade/SSRF vectors.
  - Added `Test-TrustedJvmUri` (`CWE-918` / `CWE-601`) in `:ExecuteSharedDownloader` and redirect host verification in `:VerifyDownloadedScript`, validating initial URLs and post-redirect `$response.ResponseUri` hostnames against an explicit allowlist of official vendor domains (`api.adoptium.net`, `github.com`, `objects.githubusercontent.com`, `download.oracle.com`, `corretto.aws`, `api.azul.com`, `repo.maven.apache.org`, `services.gradle.org`, etc.) to block SSRF and open-redirect attacks.
  - Made `:CheckUpdateStatus` execute unconditionally during `jvm self-update` (even when `--yes` / `-y` is passed), blocking version and monotonic `JVM_BUILD` downgrade attacks (`AHEAD_OF_STABLE` / `AHEAD_OF_NIGHTLY`).
  - Added `byte[]` UTF-8 stream decoding for `SHA256SUMS.txt` in PowerShell 7+, strict 64-hex-character SHA-256 manifest parsing (`CWE-354`), `try/finally { $zip.Dispose() }` archive handle release, and full cleanup of partial downloads (`$out`) and extraction directories (`$env:DL_EXTRACT`) in `catch` blocks (`CWE-459`).
  - *Nightly Channel Git Blob SHA-1 Cryptographic Verification (`:SelfUpdate` & `install.ps1` — `CWE-494`)*: Hardened `NIGHTLY` channel self-updates in `jvm.bat` (`:SelfUpdate` verifying `install.ps1`) and `install.ps1` (verifying `jvm.bat`) to query the GitHub Contents API (`https://api.github.com/repos/DiamTek/Java-Version-Manager-Windows/contents/<file>?ref=<ref>`) and verify the downloaded payload's Git Blob SHA-1 (`SHA1("blob " + length + "\0" + bytes)` across raw, LF, and CRLF normalized byte representations) against the commit tree's `.sha` digest, immediately aborting with `MISMATCH` on tampering or corruption.
  - *Dynamic `%ProgramFiles%` / `%ProgramFiles(x86)%` Discovery & Windows ARM64 Vendor Fallback (`:Resolve_Oracle` & `:Resolve_GraalVM`)*: Replaced hardcoded `C:\Program Files` and `C:\Program Files (x86)` references across `LOCATIONS[0..11]`, `DEST_DIR`, and `ENV_PURGE_LIST` with `%JVM_PF%` (`%ProgramFiles%`), `%JVM_PF86%` (`%ProgramFiles(x86)%`), and `%JVM_SYSDRIVE%` (`%SystemDrive%`) with safe fallbacks, and added explicit Windows ARM64 (`aarch64`) architecture warnings and `x64` Windows 11 Prism emulation fallback in `:Resolve_Oracle` and `:Resolve_GraalVM`.
  - *Cryptographic Uninstaller Trust Chain & Stale Fallback (`:UninstallJVM_Complete` & `:VerifyDownloadedScript` — `CWE-494`)*: Hardened `jvm self-uninstall` to initialize `UNINSTALL_REF=v!JVM_VERSION!` before local uninstaller discovery, verify local `uninstall.ps1` scripts against the release `SHA256SUMS.txt` on the `STABLE` channel (`for /f "usebackq ..."` result parsing), and automatically fall back to downloading and SHA-256 verifying the matching `v!JVM_VERSION!` release copy in `%JVM_SECURE_TEMP%` if a local `uninstall.ps1` is from an older release rather than aborting prematurely.
- **Strict ZipSlip, `DL_STRIP_ROOT` Argument Injection & Canonical Destination Defense (`CWE-22` / `CWE-88`)**:
  - Enforced canonical destination boundary checks (`$destinationPath.StartsWith($fullRoot, [System.StringComparison]::OrdinalIgnoreCase)`) with mandatory trailing directory separators (`\`), NTFS ADS colon (`:`) rejection, and explicit rooted-entry rejection (`$entry.FullName -match '^[/\\]'`) during ZIP archive extraction in `:ExecuteSharedDownloader`, blocking both `../` escapes and sibling prefix collisions (`../cand_evil/payload.exe`).
  - Validated top-level extracted directory names (`$items[0].Name`) in `DL_STRIP_ROOT=1` against leading hyphens (`-`) and unsafe characters (`^[a-zA-Z0-9._+-]+$`) and switched to `Move-Item -LiteralPath` (`CWE-88`), while canonicalizing `$fullD` and `$t` via `[System.IO.Path]::GetFullPath()` with trailing backslash inside the `:FetchAndExtract` elevated move script (`CWE-22`).
  - Hardened `$allowedRoots` validation in `Set-JvmVar` (`install.ps1` and `jvm.bat`) to enforce trailing directory separators (`$normRoot + '\'`), preventing sibling directories (`C:\Program Files\Java_evil` or `.jdks_evil`) from bypassing storage boundary checks.
- **Non-Destructive Directory Junction Unbinding & Profile/Terminal Symlink Guards (`Remove-DirectorySafely`, `Test-HasReparsePointInLineage`, `:CleanCache`, & `jvm pin` — `CWE-59`)**: Re-architected junction cleanup and profile modification routines across `jvm.bat`, `install.ps1`, `uninstall.ps1`, and `packages/msi/build-msi.ps1`:
  - *Target JDK Deletion Prevention*: Resolved a critical directory traversal hazard where standard recursive deletions (`Remove-Item -Recurse` in Windows PowerShell 5.1) traversed NTFS directory junctions into target directories, inadvertently deleting linked host JDKs. Introduced `Remove-DirectorySafely` and hardened `:CleanCache` (`jvm clean` / `jvm prune`) to sort reparse points bottom-up by path length and cleanly unbind junctions via `[System.IO.Directory]::Delete($_.FullName, $false)` and native `rmdir /q` before container folders are deleted.
  - *`$PROFILE`, Windows Terminal `settings.json`, & Start Menu Symlink Guards*: Added `Test-HasReparsePointInLineage` and `-LiteralPath` checks across `install.ps1`, `uninstall.ps1`, `:InstallPowerShellHook`, and `:RemovePowerShellHook`, ensuring profile scripts, Windows Terminal `settings.json`, and Start Menu `.lnk` shortcuts are never written or deleted through malicious NTFS symlinks or junctions.
  - *Reparse-Safe `.java-version` Pinning*: Hardened `jvm pin` (`:DO_PIN_WRITE`) to verify `.java-version` is not a directory, symlink, or NTFS junction (`%FSUTIL_BIN% reparsepoint query`) before writing, preventing arbitrary file overwrite via symlink attacks.
  - *Broken Junction Auto-Recovery*: Hardened `jvm.bat` and ecosystem switchers to issue direct `rmdir` calls without `if exist` guards, resolving silent switch deadlocks where broken or dangling junctions (whose target directories were deleted or moved) failed `if exist` checks and could not be re-linked.
  - *Filesystem Root & Canary Protection*: Added strict safeguards forbidding deletion of system/user roots (`C:\`, `%USERPROFILE%`, `%SystemRoot%`, `%ProgramFiles%`), requiring active JVM installation markers (`jvm.bat`, `uninstall.ps1`), and detecting active `.git` development repositories to prevent accidental source code loss.
- **Process Elevation Hardening (Base64 UTF-16LE & System32 SpecialFolder Isolation)**: Overhauled administrative UAC elevation routines (`Start-Process powershell -Verb RunAs`) across `jvm.bat`, `install.ps1`, `uninstall.ps1`, and `build-msi.ps1`:
  - *In-Memory Encoded Command Execution*: Dynamically encodes all elevated command payloads into Base64 UTF-16LE strings passed via `-EncodedCommand`, completely eliminating argument breakout vulnerabilities, parameter splitting on quotes or spaces, and temporary batch/PowerShell runner scripts in `%TEMP%` (mitigating TOCTOU race conditions).
  - *System32 SpecialFolder Working Directory & Binary Isolation*: Pinned all elevated process invocations and working directories to native Win32 `[Environment]::GetFolderPath([Environment+SpecialFolder]::System)`. By querying the Win32 Known Folder API directly rather than resolving `$env:SystemRoot` or `%SystemRoot%` from the process environment block, this completely immunizes process elevation boundaries against user-level environment variable saturation/spoofing attacks and eliminates CWE-426 binary search order hijacking.
- **User & System PATH `REG_EXPAND_SZ` Preservation & Boundary Auditing**: Hardened environment variable manipulation across `install.ps1`, `uninstall.ps1`, and `jvm.bat`:
  - *Dynamic ExpandString Preservation*: Audits registry value kinds using `Microsoft.Win32.RegistryKey.GetValueKind('Path')`, enforcing `[Microsoft.Win32.RegistryValueKind]::ExpandString` across both User (`HKCU\Environment`) and Machine (`HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment`) scopes. Guarantees that system variables (`%SystemRoot%`, `%USERPROFILE%`, `%LOCALAPPDATA%`) are preserved and never collapsed into static `REG_SZ` strings.
  - *Combined PATH Boundary Guards (2048 / 8191 Characters)*: Dynamically calculates the combined length of User PATH and Machine PATH. Aborts modification immediately if combined length exceeds the 8191-character Windows environment block limit to prevent silent environment corruption, and emits an actionable warning if length exceeds 2048 characters to alert users of potential legacy Win32 application truncation.
  - *Deduplication & Slashing Hygiene*: Automatically strips redundant quotes, trims whitespace, normalizes trailing slashes, and purges legacy phantom Oracle `javapath` entries.
- **Non-Blocking `SendMessageTimeout` Environment Broadcasts**: Overhauled Windows setting change broadcasts (`WM_SETTINGCHANGE`) using native Win32 P/Invoke `SendMessageTimeout` (`HWND_BROADCAST = 0xFFFF`, `WM_SETTINGCHANGE = 0x001A`, `SMTO_ABORTIFHUNG = 0x0002`) with a strict 3000ms-5000ms timeout window. Guarantees that environment broadcasts notify running shells without hanging or deadlocking the terminal when third-party applications fail to process messages.

- **Direct Target Directory Updates**: Removed repository directory redirection heuristics (`$isDevRepo`) in `install.ps1`, ensuring custom locations, standalone copies, and cloned workspaces update their running `jvm.bat` directly instead of silently redirecting into `%LOCALAPPDATA%`.
- **Commit SHA Handoff Forwarding**: Forwarded the dynamically resolved GitHub commit SHA (`-Branch "!REMOTE_REF!"`) from `jvm.bat` to `install.ps1` to eliminate duplicate API calls, bypass Fastly CDN edge caching on `HEAD`/`main`, and guarantee newly installed scripts immediately reflect the latest build version.
- **Live Terminal Memory Collapse**: Resolved a critical bug where running the uninstallation or switch commands could completely destroy all native Windows commands (`findstr`, `choice`) in the active session. This occurred because the previous path-scrubber relied on batch string substitution (`!PATH:string=!`), which suffered catastrophic quote-collisions when evaluating complex paths containing double quotes or undefined variables. Completely replaced all batch substitution with safe, native PowerShell `-not` array evaluations.
- **UTF-8 BOM Interpretation**: Fixed critical Windows `cmd.exe` UTF-8 BOM interpretation bugs and UNIX (LF) line-ending crashes (the `cho` bug) by enforcing explicit CRLF encoding during downloads.
- **Double-Quote `PATH` Encapsulation**: Hardened all `for /f` variable export loops with double-quote encapsulation to prevent `cmd.exe` from misinterpreting `PATH` strings containing embedded quotes as file lists.
- **Exclamation Mark Corruption**: Fixed delayed expansion parsing bugs that corrupted custom paths containing exclamation marks (`!`).
- **Oracle Update Crash**: Fixed Oracle update checks crashing with `'$' is not recognized` by switching the PowerShell payload to pipe-safe string concatenation.
- **Forward Compatibility**: Replaced deprecated `wmic` environment queries with direct `reg query` calls for guaranteed forward compatibility with Windows 11.
- **Variable Slicing Errors**: Hardened the Global Command installer and resolved subshell variable slicing errors.
- **Cross-Architecture Registry Conflicts**: Fixed conflicts between User and Machine environment variables causing ghost path artifacts.
- **UAC Deadlocks**: Fixed edge-case UAC elevation deadlocks during global registry writes.
- **Directory Protection**: Added a conditional `rmdir` guard to prevent extracted files from being destroyed if a junction move failure occurs.
- **Navigation State Leaks**: Patched a variable state-leak during cross-menu navigation and stabilized the back-navigation structural loop across all interactive UI hubs.
